🔑账号从哪来

  • 教师账号：系统内置（如 teacher），首次使用请立即在系统配置中改密。
  • 学生账号：教师端「学生管理」逐个添加，或批量导入（每行 用户名 姓名 密码，密码可省略）。
  • 默认密码 123456，批量导入省略密码时也是它 —— 建议第一节课让学生自行改密（学生端「我的」可改）。
  • 同一用户名已存在时再导入，只会把该生转入当前班级，不会重复建号。
端口说明：默认端口 3001；若被占用，可用环境变量 PORT 指定，实际地址一律以启动后的控制台提示为准。

1

学习 · 考点精讲（16 章）

按江苏学测考纲拆成 4 大部分 / 16 章 / 70 小节，讲义即考点，可就地跳转练习。

📖怎么用

  • 左栏按部分列出 16 章，点章名展开小节，章/节后面都标着题量。
  • 右栏是讲义正文；每个小节标题右侧有「去练习 N」按钮 —— 点了直接开练习窗口并自动带上该小节筛选。
  • 章头两个常用按钮：去练习这一章（N 题） / 章末自测（已看/总数）。
  • 章末自测点开后会跳转 AI 答疑，边测边问。
  • 顶部有全平台进度条，显示「自测已看 X/Y」。
进度口径：学习进度 = 章末自测已看数 ÷ 自测总问数，不是题库总题数；章头「已掌握 N 题」走的是练习掌握口径。
2

练习 · 刷题主阵地

✏️开局设置

  • 首屏先给统计卡：总做题 / 已掌握 / 做对 / 做错 / 正确率。
  • 两种筛选可叠加：标签筛选 + AI 聚类筛选（先选一级类目，再选二级小节）。
  • 实时显示「当前符合条件的题目 N 道」，再点开始练习。
  • 题型支持单选、多选、填空、综合题（逐小题作答）。

⚖️判分与答案

  • 判分一律服务端裁定，前端说了不算。
  • 题目下发时不含答案与解析；提交后服务端才回传正确答案、解析、小题对错。
  • 提交后立刻看到对错、暴击特效、本次积分、连对/连错。
  • 答错可点「同类题强化练习」巩固（不计分、不掉装备）。
掌握门禁：同一题累计答对达到「掌握题目阈值」（默认 3 次，实际以教师端设置为准）后，该题不再计分、不再掉装备，并自动移出练习队列，提示「已掌握」；答错达阈值后本次不再扣分。
3

测试 / 考试 / PK 对战

这三个都在桌面「测试」窗口里，以页签切换。

📋普通测试

  • 教师配好题数与范围，系统随机抽题。
  • 卡片显示题数、限时、奖励积分、今日剩余次数。
  • 参加资格：需同时满足「累计做对 N 题」和「掌握 N 题」，不达标按钮显示「资格不足」并说明差多少。
  • 可设每日次数上限，用完提示明天再来。

📄试卷（考试）

  • 教师手工组卷，题目固定，不随机。
  • 显示及格分、及格奖励积分、奖励上网码个数。
  • 结束后不能再提交；结果页显示得分、是否通过、获得积分与上网码（可复制）。
  • 考试不受掌握门禁约束，也不计入练习掌握次数。

⚔️PK 对战

  • 大厅选活动 → 快速匹配 / 建房 / 输房间码加入。
  • 2 人同题同时开始：对 +1 分，错 -1 分；倒计时结束统一收卷，分高者胜，同分比总耗时。
  • 掉线超 60 秒判负；可中途投降（判负）。
  • 结算看：胜负、段位升降、获得积分、掉落装备与荣誉、参与奖励，还能双击题干逐题复盘（选项/答案/解析）。

🏅PK 段位：小学生 → 研究生

🎒小学生起点
📚初中生满 5 星升
🏫高中生满 5 星升
🎓本科生满 5 星升
🔬研究生星数无上限
  • 对手同级或差 1 级：胜 +1 星 +1 PK 分，负 −1 星 −1 PK 分。
  • 差 ≥2 级：低段赢 +2/−1，高段赢 +0/−0（保护高段位）。
  • 满 5 星再赢 → 升一级并置 1 星；0 星再输 → 降一级到 5 星（小学生 0 星保底）。
  • 达到段位会永久解锁对应段位皮肤（掉段不回收），皮肤带来暴击加成。
4

错题集与课堂任务

❌错题集

  • 练习 / 测试 / PK 中判错会自动收进来，重复错会累加次数。
  • 可按标签筛选，也能「仅看未解决」。
  • 重做判对 → 自动标记已解决并移出列表；仍错则保留并累加次数。
  • 答案同样走「答过才给」的接口，不能提前偷看。

📚课堂任务

  • 顶部「课堂任务」按钮打开，显示未开始 / 进行中 / 已完成 / 已逾期。
  • 内容含学习目标、资源（PDF/PPT/视频/HTML 等）、随堂练习。
  • 视频需看到 90% 才解锁随堂练习；密码任务需老师给的口令。
  • 离开页面会提示可能影响学习记录。

游戏化系统（激励核心）

积分、暴击、装备、萌宠、皮肤、荣誉 —— 这套让刷题变成"打怪升级"。

💰积分怎么赚

  • 答对 +10 分（默认），答错 −5 分（默认），具体值教师可在「刷题打怪系统」改。
  • 测试/考试按教师配置发放；PK 按活动公式结算。
  • 积分不会被扣成负数，不足时提交直接被拒。
  • 积分用途：兑换奖品、上网认证码、按次付费应用。

⚡暴击率怎么算

暴击率 = min( max( 基础 5 + floor(累计答对数 / 100) + 额外暴击 + Σ Buff + Σ 装备暴击 + 皮肤暴击, 5), 上限 30 ) （单位 %） 命中暴击 → 本次得分 ×2
  • 上限默认 30%、下限 5%，教师端可改。
  • 「我的 → 个人中心」能看到逐项来源（基础/答对数/Buff/装备/皮肤各贡献多少）。

🐾战力与萌宠

  • 战力倍率 = 1 + 0.1 × 萌宠等级；实际得分 = 基础分 × 战力倍率。
  • 萌宠等级越高战力越强，没有上限；可换养、可选择形态。
  • 桌面「萌宠」图标进入养成。

🎁装备掉落

  • 答对时对每件启用的装备独立掷骰，掉了会弹出掉落特效。
  • 装备按 暴击加成 × 持有数量 累加到暴击率，永久有效。
  • 掉落倍率：练习随机、考试 10 倍、PK 按活动系数（≤5）。

🏆荣誉与 Buff

  • 荣誉：十全十美（连对满 10）、三连暴击、勤学好问（当天 AI 答疑满 10 次）、屡败屡战、运指如飞。

  • Buff 是限时暴击修正，桌面右上角常驻显示当前生效 Buff。

开课前：班级与学生

🏫班级管理

  • 填名称即创建；每个班有一排总开关，是课堂管控的总闸：
  • 允许登录 / AI答疑 / 数字消息 / 创意工坊 / 应用中心 / 兑换 / 上网 / PK对战 / 编程。
  • 关掉「允许登录」→ 该班学生提示「平台暂未开放」，已登录的会在 30 秒内被踢出。
  • 上网开关变更会立即刷新代理缓存，不用重启。

👥学生管理

  • 先选班级，再添加学生（用户名 / 姓名 / 密码）。
  • 批量导入：每行 用户名 姓名 密码，空格或逗号分隔，密码省略即 123456。
  • 支持按积分 / 做题量 / 正确率 / 在线状态排序。
  • 批量操作：重置密码（并强制下线）、批量改积分、开关兑换权限。

📚题目与题型

  • 三种题型：选择题 / 填空题 / 综合题（含子题，可多选）。

考试管理：测试 / 试卷 / PK 对战

「考试管理」左侧挂普通测试，子页签「试卷」里同时放着试卷、对战配置与对战数据。

📋普通测试（随机抽题）

  • 设题数、范围（标签 + 聚类，叠加需同时满足）、限时、及格分、奖励积分。
  • 每日次数上限（0 = 不限）。
  • 参加资格两项须同时满足：累计做对 N 题、掌握 N 题（可限定一级类目范围）；留空/0 = 不启用。
  • 可配及格后奖励：认证码、开通上网 / 兑换 / 应用中心、及格掉装备（10 倍掉率）。

📄试卷（手工组卷）

  • 固定题目，可选难度、是否允许查看试卷（allow_view_paper）。
  • 只能选标记了「可考试」的题目。
  • 结束考试：未参加记 0 分，未提交的按当前进度自动评分，已提交不变。
  • 可按学生 / 按题目查看，并导出 Excel。

⚔️对战配置（PK 活动）

  • 基础：名称、投放班级（不选 = 全部班级可用）、模式、时长（默认 180 秒）、题量（默认 20）、每日上限、难度范围、标签/聚类。
  • 资格同普通测试。
  • 奖励：积分倍率 0.1–10（默认 1）、赢方加成（默认 0.5 即 ×1.5）、平局加成、惜败补贴（分差默认 2）、每日首战、单日达标场次。
  • 单场积分 = 做对题数 × 每题基础分 × 倍率 × 胜负加成（输方恒 ×1，做对就有分）。
  • 装备掉落默认关；实际掉率 = 装备掉率 × 系数（≤5），且至少做对 1 题才掷骰。
投放班级的三种状态：一个班都不选 = 全部班级可见；只勾某几个班 = 仅这些班可见；已配置的再清空 = 恢复全部可见（不会变成"谁都看不见"）。

📊对战数据（7 类统计）

  • 总览：参与率、场次、人均场次、正确率、平均每题耗时、积分发放。
  • 按活动：场次/人数/正确率/时长，会标出「从未被参与」。
  • 段位分布与趋势（7/30/90 天升降段、升星掉星）。
  • 高频错题榜：只统计 PK 作答，双击题干看选项/答案/解析，讲评利器。
  • 正确率分布（仅统计 ≥3 场者）、学生明细（胜率/连败/系统积分，连败 ≥3 需关注）。

学情分析

📈看什么、怎么判

  • 概览卡：积分 / 正确率 TOP10、萌宠等级分布。
  • 学生详细数据：积分、做题量、正确率、总掌握，表头可排序。
  • 章节掌握进度：掌握率 = 已掌握题数 ÷ 章节总题量。
  • 错题排行：取前 100 题，含选项分布与「最强迷惑项」，可批量标记已讲解/打标签。
  • 个人学情曲线：近 8 周走势。
  • 掉队预警三条：未登录 ≥3 天；近 7 天正确率比前 7 天低 15 个百分点（且两侧 ≥5 次）；近 30 天做题量 < 班级人均 50%。
  • 考试成绩分布（仅试卷）：参考率、平均分、及格率、优秀率（≥85）。
掌握的统一口径：同一题在练习（source='practice'）中累计答对达到「掌握题目阈值」即算掌握；章节按一级类目统计，天然包含其下所有小节。测试/考试不计入掌握次数。
6

课堂管控：点名 · 上网 · 通知

🙋课堂点名

  • 三栏：学生列表 / 座位画布 / 详情或讲台备忘录。
  • 拖动换位；拖到空白处清空；双击学生 = 远程查看桌面（只读或接管，5 分钟失效）。
  • 工具栏：反向排座、自动排座、随机点名、考勤、班级备忘录、一键绑 IP、登录限制、批量上网开关。
  • 右栏显示当前 IP 与绑定 IP（不符标异常）、关爱/推荐标记、可重置密码。
  • 考勤可生成免登录链接给班主任。

🌏上网管理

  • 白名单：名称/URL/图标/排序（小者靠前），域名逐行，.example.com 前导点通配子域；可一键自动获取子资源域名。
  • 待审核域名：学生访问未白名单的站会自动记录，可批准 / 忽略 / 一键批准。
  • 访问记录（近 100 条，按班筛选）；缓存 100–51200 MB，超限淘汰最久未访问。

🔔通知管理

  • 新建：标题 + 内容必填；对象可选全体 / 指定班级 / 指定学生。
  • 可附：奖励积分、扣除积分、临时 Buff（暴击修正 % + 时长）、允许兑换/应用。
  • 勾「允许上网」即给接收者开通上网。
  • 填定时时间 = 定时发送（每分钟检查一次）；不填 = 立即发送。
7

激励体系配置

🎮刷题打怪系统

  • 积分规则：答对 / 答错分值、掌握题目阈值、领养与换养萌宠的积分。
  • 打怪系统：基础暴击率 %、暴击率上限 %，以及十连对、三连暴击、勤学好问（当天 AI 答疑满 N 次，每日限一次）、运指如飞等 Buff（暴击加成 % + 时长），三连错 Debuff。
  • 装备掉落：名称/图标/掉落概率 %/暴击加成 %/启用；禁用不影响已持有者。

🎁积分兑换管理

  • 奖品类型：普通 / 上网认证码 / 装备 / 皮肤。
  • 可设所需积分、库存（−1 = 无限）、每日限制、班级可见性。
  • 认证码支持导入、批量删除、清理一周前的旧码；可看总数/已用/未用。
重要限制：皮肤下拉只列积分兑换类；段位专属皮肤禁止作为奖品（只能靠 PK 升段解锁），后端兑换接口也会拦截。

🐾萌宠配置

  • 名称、领养门槛、5 张阶段图；第 N 级所需累计成长值 = 基础阈值 + (N−1) × 每级增量。
  • 阶段数 1–5 只控制图片，等级本身没有上限。
  • 含食物、提示语、桌面设置，以及专注模式（按班生效：桌面只显示指定图标，萌宠变悬浮按钮）。

🧩应用管理

  • 类型：学习工具 / 编程实训 / AI答疑 / 心理健康 / 游戏 / 模拟 / 外部链接 / HTML网页 / 魔法学院 / 代码秘境 / 键盘星域。
  • 价格：免费 / 积分兑换 / 按次收费；可上架下架。
  • 可见班级：不勾 = 全部可见。
  • 学生端还需班级总开关里的「应用中心」打开才看得到。

常见疑问

学生说「资格不足」，是什么意思？
测试/PK 可设参加资格，需同时满足两个条件：累计做对 N 题、掌握 N 题（可限定章节范围）。学生点按钮会弹窗告诉他当前差多少，让他先去练习补够即可。
为什么学生做了很多题，积分却不再增长？
同一题累计答对达到掌握阈值（默认 3 次）后会自动移出练习队列，不再计分、不再掉装备。这是防止刷同一题刷分的保护机制，属于正常现象。
学生的暴击率一直是上限 30%，皮肤加成看不出效果？
暴击率会被 crit_max_rate（默认 30）截断。做题多的老账号各项加成之和早已超过上限，此时再加皮肤也看不出变化；新建的账号则能明显看到差异。若想拉开差距，可在教师端调高暴击率上限。
PK 活动设了「投放班级」，为什么有的班看不到？
投放班级的语义是：一个班都不勾 = 全部班级可用；勾了某几个班 = 只有这些班可用。若某班看不到活动，检查是否被勾选；想让所有人可用，用「清空」恢复为不限班级即可。
段位皮肤能用积分兑换吗？
不能。5 套段位皮肤（启明书包/青竹书卷/墨韵青锋/紫宸星槎/太初鸿蒙）只能靠 PK 升到对应段位自动解锁，兑换中心的下拉里根本不会出现它们，后端也会拦截。这样设计是为了让段位有含金量。
启动服务时报「Migration checksum mismatch」警告？
这是迁移基线校验提示，不影响功能：日志会显示「已跳过校验继续启动」和「Database migrations are up to date」。当前版本会自动把基线对齐，下次启动即不再出现。
学生被踢下线 / 提示「登录状态已失效」？
多半是单设备登录策略：同一学生新登录一次，旧会话立即失效（系统配置 → 安全配置里的「最大并发会话数」与「允许多设备登录」）。若机房存在多标签页/多窗口需求，建议把学生并发数放宽到 3 以上。
如何备份与迁移整站数据？
教师端「系统配置 → 数据管理」：导出勾选数据域生成 .xgpybak（含数据库与上传文件）；换机器时导入即可，可选覆盖/追加/跳过，导入前系统会自动快照并保留最近 5 份。
学生端的哪些功能是"授权功能"？
课堂任务、应用中心、萌宠、兑换、上网冲浪、课堂点名、AI 创意工坊属授权功能，未授权时图标显示锁标并提示。教师端对应菜单（应用、兑换、萌宠、打怪、上网、点名、学情、工坊）同理。
